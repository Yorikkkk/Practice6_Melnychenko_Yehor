## Відповіді на контрольні питання

### 1. Що таке immutable об’єкт? Для чого об’єкти класу String зробили імутабельними? Чому клас String задекларований як final?

* **Immutable (незмінний) об’єкт** — це об’єкт, внутрішній стан якого неможливо змінити після його створення. Будь-яка операція модифікації рядка (конкатенація, заміна символів, зміна регістру) створює в пам'яті новий об'єкт `String`, залишаючи початковий без змін.
* **Навіщо `String` зробили імутабельним:**
    1. **String Pool (пул рядків):** Дозволяє JVM повторно використовувати однакові рядкові літерали в пам'яті (економія оперативної пам'яті), не боячись, що зміна однієї змінної зіпсує значення іншої.
    2. **Безпека (Security):** Рядки широко використовуються для передачі паролів, URL-адрес, імен файлів та параметрів підключення до БД. Імутабельність гарантує, що рядок не буде підмінено між перевіркою прав доступу та його використанням.
    3. **Потокобезпека (Thread-safety):** Незмінні об'єкти можна безпечно використовувати в багатопотоковому середовищі без додаткової синхронізації.
    4. **Кешування `hashCode`:** Оскільки рядок не змінюється, його хеш-код обчислюється лише один раз при першому зверненні, що робить `String` ідеальним ключем для `HashMap` та `HashSet`.
* **Чому клас `String` задекларований як `final`:** Щоб заборонити успадкування від класу `String`. Якби можна було створити підклас, програміст міг би перевизначити його методи і порушити гарантії незмінності (імутабельності) та безпеки.

### 2. Що таке регулярні вирази? Наведіть приклади регулярних виразів.

**Регулярні вирази (Regular Expressions / RegEx)** — це формальна мова шаблонів (патернів), яка використовується для пошуку, перевірки відповідності, розбиття або заміни підрядків у тексті. У Java вони підтримуються через пакет `java.util.regex` (`Pattern`, `Matcher`) та методи класу `String` (`matches()`, `split()`, `replaceAll()`).

**Приклади регулярних виразів:**
* `\\d+` або `[0-9]+` — одне або більше цілих чисел (цифр від 0 до 9).
* `[a-zA-Z]+` — слово, що складається виключно з латинських літер.
* `\\s+` — один або кілька пробільних символів (пробіл, табуляція, перенесення рядка).
* `^[0-7]+$` — рядок, що містить лише цифри вісімкової системи числення.
* `^[\\w.-]+@[\\w.-]+\\.[a-zA-Z]{2,}$` — базовий шаблон для перевірки електронної пошти (email).

### 3. В чому полягає різниця між оператором `==` та методом `equals()`?

* **Оператор `==`** для посилальних типів (зокрема для об'єктів `String`) порівнює **посилання (адреси в пам'яті)** — тобто перевіряє, чи вказують обидві змінні на один і той самий фізичний об'єкт у купі (Heap) або пулі рядків.
* **Метод `equals()`** (перевизначений у класі `String`) порівнює **фактичний вміст (послідовність символів)** двох рядків.
* **Висновок:** Два об'єкти `new String("Java")` та `new String("Java")` при порівнянні через `==` повернуть `false` (різні об'єкти в пам'яті), але `equals()` поверне `true` (однаковий текст). Для порівняння значень рядків у Java завжди слід використовувати `equals()`.

### 4. Для чого потрібні класи StringBuilder та StringBuffer?

Оскільки `String` є незмінним, часта конкатенація рядків (наприклад, у циклі через `+`) створює безліч тимчасових об'єктів у пам'яті та сильно сповільнює програму. Для ефективного формування та модифікації рядків використовують змінні (mutable) буфери символів:
* **`StringBuilder`** — клас для швидкої модифікації рядків (методи `append()`, `insert()`, `delete()`, `reverse()`). Він **не синхронізований** (не є потокобезпечним), тому працює максимально швидко і є стандартним вибором для однопотокових програм.
* **`StringBuffer`** — аналог `StringBuilder` із таким самим набором методів, але всі його методи **синхронізовані (`synchronized`)**. Використовується тоді, коли один рядок одночасно змінюють кілька потоків (потокобезпечний, але повільніший за `StringBuilder`).

### 5. Яким чином простіше всього прибрати пробіли на початку та кінці об’єкту String?

Для цього найпростіше використати вбудовані методи класу `String`:
1. **`str.trim()`** — класичний метод (доступний з Java 1.0), який видаляє всі пробіли та керуючі символи з кодом $\le \text{U+0020}$ на початку та в кінці рядка.
2. **`str.strip()`** — сучасніший метод (з'явився у Java 11), який коректно видаляє всі пробільні символи за стандартом **Unicode** (включно з нерозривними пробілами, які `trim()` ігнорує).
